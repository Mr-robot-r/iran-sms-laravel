# پارس گرین (ParsGreen)
- این ارائه‌دهنده API اختصاصی برای ارسال پیامک OTP دارد (متد SendOtp).

- این ارائه‌دهنده از ارسال یک الگو به چند شماره تلفن به‌صورت هم‌زمان پشتیبانی می‌کند.

- متغیرهای الگو باید به‌صورت جفت کلید-مقدار ارسال شوند.

- این ارائه‌دهنده از دفترچه تلفن پشتیبانی کامل دارد (گروه‌ها: GroupAdd, GroupEdit, GroupDelete, GroupList / مخاطبین: ContactAdd, ContactList, ContactDelete, ContactCount).

- احراز هویت از طریق هدر ApiKey انجام می‌شود.

# ملی پیامک (Meli Payamak)
- این ارائه‌دهنده API اختصاصی برای ارسال پیامک OTP ندارد. به‌جای آن از روش مبتنی بر الگو استفاده کنید.

- این ارائه‌دهنده از مدیریت کاربران پشتیبانی می‌کند (AddUser, AddUserWithUserNameAndPass, ChangeUserCredit, AuthenticateUser, ForgotPassword, GetUserCredit, GetUserDetails).

- احراز هویت از طریق username و password انجام می‌شود (برای امکانات پیشرفته از SOAP استفاده می‌شود).

# رایگان اس‌ام‌اس (RayganSms / ترز رایان افزار)
- این ارائه‌دهنده از وب‌سرویس اختصاصی برای ارسال پیامک OTP پشتیبانی می‌کند (متدهای SendMessageWithCode.ashx و SendCode).

- برای ارسال الگو، علاوه بر نام کاربری و رمز عبور نیاز به توکن دسترسی (AccessHash) دارید. برای سایر موارد، فقط نام کاربری و رمز عبور لازم است.

- متغیرهای الگو باید به‌صورت جفت کلید-مقدار ارسال شوند.

- می‌توانید یک الگو را در یک درخواست API به چند شماره تلفن ارسال کنید.

- این ارائه‌دهنده از دفترچه تلفن پشتیبانی نمی‌کند.

- این ارائه‌دهنده از لیست سفید پشتیبانی می‌کند (ShowWhiteList - خروجی لیست شماره‌هایی که در لیست سیاه نیستند).

- احراز هویت از طریق Basic Auth (username/password) انجام می‌شود.
